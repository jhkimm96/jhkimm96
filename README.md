# 김지희

Spring Boot 기반 백엔드를 개발합니다. 상품 도메인과 검색, 추천 기능을 구현하고, 문제를 해결하며 내린 판단을 기술 기록으로 남깁니다.

[포트폴리오](https://jiheeportfolio.vercel.app) · [설계와 문제 해결 기록](https://jiheeportfolio.vercel.app/engineering)

## 주요 프로젝트

### PromptHub

AI 프롬프트를 등록하고 검색하며 거래하는 팀 프로젝트입니다. 상품 도메인과 검색 파이프라인, 독립 ai-service 개인화 추천을 담당했습니다.

- PostgreSQL 원본과 Elasticsearch 검색 사본을 분리하고 변경 상품을 증분 색인
- OpenAI 임베딩과 pgvector 기반 의미 검색, RRF 하이브리드 검색
- 장바구니와 구매 활동을 이용한 개인화 추천

[팀 백엔드](https://github.com/prgrms-be-adv-devcourse/beadv6_6_3JMT_BE) · [담당 범위와 기술 기록](https://jiheeportfolio.vercel.app/projects/prompthub)

### Career Link

구직자, 기업, 관리자를 위한 채용 플랫폼 팀 프로젝트입니다. 권한별 메뉴와 공통코드 등 어드민 기반, 지원자 이력서·자소서·스크랩 CRUD, 프론트엔드 초기 셋업을 담당했습니다.

[백엔드](https://github.com/hha6571/career-link) · [프론트엔드](https://github.com/jhkimm96/career-link-ui) · [담당 범위와 기술 기록](https://jiheeportfolio.vercel.app/projects/career-link)

### Engineering Portfolio

프로젝트별 설계 결정, 트러블슈팅, 코드 리뷰와 품질 측정을 MDX 문서로 관리하는 개인 사이트입니다. Next.js와 Velite를 사용합니다.

[저장소](https://github.com/jhkimm96/jihee-portfolio) · [사이트](https://jiheeportfolio.vercel.app)
